# الطول — الريل بطول التعليق الصوتي | Length

**مفيش طول مستهدف للفيديو.** الفيديو **بيساوي** مدة التعليق الصوتي (VO)، وأي رقم تاني في الشغل
مشتق منه. ممنوع تخطّط لرقم مدة مقدّمًا أو تطوّل/تقصّر الفيديو عشان توصل له.

## الطول بيخرج من فين؟

```bash
# 1) حضّر ماستر التعليق (24kHz mono PCM16 زي ما المحركات متوقعة)
ffmpeg -y -i assets/vo/<voice>.mp3 -ac 1 -ar 24000 -c:a pcm_s16le out/vo24.wav

# 2) قيسه — بيطلّع المدة + حدود المشاهد من السكتات
python3 tools/vo_length.py out/vo24.wav --json plan/beats.json      # أو: make length VO=out/vo24.wav
```

القياس بيعمل ٣ حاجات:

1. **المدة** بـ`ffprobe` = طول الفيديو بالظبط (مش تقدير).
2. **حدود المشاهد**: قطع عند **منتصف كل سكتة** أطول من `--min-gap` (افتراضي 0.30 ث)، وأي مشهد
   أقصر من `--min-scene` (1.2 ث) بيتدمج مع اللي بعده — لأن مشهد 0.4 ث مش مقروء أصلًا.
3. **`plan/beats.json`**: `{"duration", "bounds", "scenes": [{start, end, dur, frames}]}` — نفس الشكل
   اللي `new_project.py` بيعمله فاضي.

## إزاي كل حاجة بتقرأ الرقم ده

| المحرك / الملف | الحقل | القاعدة |
|---|---|---|
| K — `src/data.js` | `DURATION = scenes.at(-1).end` | آخر `end` = مدة الـVO |
| P — `scenes.py` | `B=[...]` | `B[-1]` = مدة الـVO |
| R — `src/data.ts` | `plan/beats.json` | Composition frames = المدة المقاسة × 30fps; الرندر يرفض timeline ناقص |
| P — `mix.py` | `TOTAL` | بيتقري من الـVO نفسه، والأحداث بتتقدّم على `B` |
| `tools/sfx_kit.py` | `--length` | لو مش موجود = طول الـVO تلقائيًا |
| P — `run_all.py` | `N` | عدد الفريمات من طول الـVO (و`scenes.B` fallback بس لو مفيش VO) |
| K — `src/render.js` | `--audio` | بيحذّر لو الصوت مش بطول نافذة الرندر |
| الكابشن/الـprogress bar | `t / dur` | بيتحركوا بنسبة الطول الفعلي |

## بوّابة قبل الرندر | Gate

```bash
python3 tools/vo_length.py out/vo24.wav --check projects/<slug>
# OK    → الريل بطول التعليق بالظبط، كمّل
# !! MISMATCH +27.00 s → حدود المشاهد قديمة/مفترضة، رجّع بناءها من الصوت
```

الفشل هنا معناه إن الصوت هيتقطع أو الفيديو هيخلص وفيه كلام لسه — ده أشهر عيب في ريلات بالـAI.

## دمج الصوت مع الصورة | Mux

`mix.py` بيسيب **0.3 ثانية** ذيل للـdecay بعد آخر كلمة (مقصود، عشان الصوت ميتقطعش). الفيديو لازم
يفضل بطول الـVO بالظبط، فالدمج بيقصّ على أقصر ستريم:

```bash
# الماستر النهائي: نفس طول الصورة، والصوت مقطوع على نهايته
ffmpeg -y -i out/video_only.mp4 -i out/final_audio.wav \
  -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k -ar 48000 \
  -movflags +faststart -shortest out/master.mp4

python3 tools/vo_length.py out/master.mp4 | head -1        # لازم يساوي مدة الـVO
```

## ليه مش بنحدد طول؟

- طول التعليق هو اللي بيحدد إيقاع الكلام؛ مشهد مقصوص عشان «نوصل ٦٠ ث» بيبان مقطوع.
- صوت أطول = مشاهد أكتر، مش سرعة أكتر. متزوّدش سرعة الـVO عشان تدخل في رقم.
- الاختبار `tests/test_vo_length.py` بيفشل لو أي ملف في الوثائق أو القوالب رجّع رقم طول ثابت.
