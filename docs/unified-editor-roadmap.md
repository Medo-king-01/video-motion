# خارطة إكمال منصة التحرير الموحدة

هذه خارطة متابعة للعمل القادم وليست إعلان اكتمال. التفاصيل والقرارات وحدود النواة الحالية في
[عقد المشروع الموحد](unified-project-contract.md). يجب الحفاظ على المشاريع والمسارات القديمة كما هي
حتى تُنفذ هجرة آمنة صريحة، وعدم نسخ كود أو أصول خارجية دون مراجعة تراخيصها؛ راجع
[مراجعة المصادر](editor-source-review.md).

## ما أُنجز حتى الآن

- schema وفاحص دلالي تجريبيان للإصدارين 1.0 و1.1؛ وسائط على timeline، وشفافية وكسب وkeyframes
  محدودة للتمثيل والتقييم فقط. الحقول والإصدارات غير المعروفة تُرفض، ولا توجد هجرة تلقائية.
- دوال إنشاء وتحرير نقية للمشروع والمسارات والمقاطع والمؤثرات، مع split وtrim وmove وripple delete
  وsnap وundo/redo في الذاكرة. بعض عمليات المقاطع المتحركة تُرفض بدل فقد البيانات.
- حفظ محلي ذري بقفل تعاوني وكشف تعارض، واستيراد وفحص وسائط محلية ببصمة SHA-256 وحدود موثقة.
- خطة render graph أولية غير قابلة للتنفيذ العام، ومعاينة Python مرجعية لإطارات صور PPM فقط،
  وتصدير مرجعي صامت محدود إلى FFV1/MKV باستخدام FFmpeg. لا يوجد adapter موحد لـP/K/R/Hybrid.

## العمل المتبقي، بترتيب مقترح

1. **العقد والحفظ:** حسم وتوسيع تمثيل النص العربي والخطوط والصوت واختيار streams والانتقالات
   والسرعة والتراكيب، ونسخ effects والنقاط عند split/trim دون فقد؛ هجرات قابلة للاختبار وفتح آمن
   للإصدارات الأحدث، autosave واسترداد وتعامل واضح مع التعارض والملفات المفقودة وتغيير البصمة.
2. **محرك التنفيذ:** تعريف graph تنفيذي وقدرات محددة مع فشل صريح؛ فك صور وفيديو وصوت فعليًا،
   معالجة timestamps وVFR والصوت والمزج والشفافية واللون، ومطابقة المعاينة والتصدير. ثم adapters
   لـP وK وR وHybrid حسب قدراتها المثبتة؛ لا تدّعي المساواة بينها أو تسقط ميزات دون إشعار.
3. **المحرر المرئي:** Media Bin وPreview وTimeline متعدد المسارات وInspector وKeyframe Editor
   وProject Panel؛ ربط عمليات النواة، undo/redo وautosave وsnap وsplit وtrim وripple delete
   والنقل بين المسارات. أي عنصر واجهة يجب أن يكون له تمثيل ومعاينة ورندر أو رفض واضح.
4. **طرق العمل:** Free Edit وScript to Video وTalking Head وMontage وPodcast وExplainer وProduct
   Review وMotion Design؛ كل منها ينشئ مشروع timeline موحدًا قابلًا للتحرير، لا فيديو مغلقًا فقط.
   لا AI لاتخاذ قرارات التحرير أو إنتاج المشاهد داخل قلب المحرك.
5. **التصدير والجودة:** صيغ وإعدادات تصدير فعلية، فحص أصول وقدرات قبل البدء، تقارير تقدم وأخطاء
   وإلغاء وتنظيف؛ اختبارات جودة وتكرار داخل بيئة مثبتة وحواف الصوت والفيديو والنص العربي.
6. **التوافق والتشغيل:** اختبارات Windows الأصلية وLinux، المشاريع القديمة والهجرة غير المدمرة،
   أمن الملفات والمجلدات، وأداء مشاريع كبيرة؛ لا يُفترض أن اختبارات Linux تثبت دعم Windows.

## معيار التسليم

لا تعتبر المنصة مكتملة إلا بعد ربط واجهة عملية بكل الطبقات وإثبات مشاريع ممثلة لجميع طرق العمل من
الإنشاء والتحرير والحفظ وإعادة الفتح حتى المعاينة والتصدير والفحص، مع اختبارات تلقائية وتوثيق
القيود المتبقية. حتى ذلك الحين فالنتائج الحالية أساس تجريبي وليست محرر فيديو كاملًا.
