**التاريخ:** 2026-11-10 · **الفرع:** `arena/b194dc1a-video-motion` · **نقطة الأساس:** `842d609`
**نطاق المراجعة:** الكود (P/K/R/Hybrid)، الأدوات، الاختبارات، التوثيق، الأصول، الـCI، التراخيص، والأمان.

## 0. الملخص التنفيذي

`video-motion` ليس "سكربت رندر"، بل **استوديو إنتاج ريلز عمودي (1080×1920 @30fps) بعقد تشغيل مكتوب**، يعمل مع أي وكيل برمجي، ويملك ثلاثة محركات رندر مستقلة (Python، Canvas، React) فوق **هوية بصرية مقفولة ميكانيكيًا**، وطبقة **بوابات جودة قابلة للقياس** (lint + stage gates + media QA).

**أهم ست نتائج:**

1. **المشروع سليم وظيفيًا.** بعد تثبيت المتطلبات الموثّقة (`pip install -r tools/requirements-dev.txt` + `npm ci --prefix tools/toolkit`) أصبحت الحزمة كاملة: **1,394 اختبارًا → 1,380 ناجح، 14 متخطّى، 0 فاشل**، و`ruff` نظيف، و`compileall` سليم، ورندر حقيقي لمحرك P نجح، و`tsc --noEmit` لمحرك R نجح، وChromium يعمل.
2. **الفصل المعماري هو أقوى ما في المستودع:** طبقة هوية (`brand.json`) → طبقة عقود خطة (`plan/*.json`) → طبقة تنفيذ (3 محركات) → طبقة تحقق (45 قاعدة lint + 6 بوابات مراحل + 6 فحوصات وسائط). هذا هو ما يمنع الفيديو من "الانحراف" مع كل تعديل.
3. **أكبر خطر ليس في الكود، بل في التوثيق الرقمي المتناقض:** مكتبة التقنيات مذكورة في نفس المستودع بأربعة أرقام مختلفة (**59 / 334 / 1434 / 2239**) والحقيقة المقاسة هي **2,239 تقنية في 44 فئة**. وبما أن العقد يعتمد على الوثائق، فإن الرقم الخاطئ قرار إنتاجي خاطئ.
4. **ستة سكربتات في `tools/` مكتوبة بمسارات مطلقة `/home/user/video-motion/...`** وتقرأ من `/tmp/...`؛ تعمل على هذا الجهاز فقط، لكنها معروضة في الوثائق كأدوات استوديو.
5. **CI يتحقق من 12 ملف اختبار فقط من 78 على الـPR** (نحو 15% من الحزمة)، والتحقق الكامل يعمل ليليًا فقط؛ وثلاثة مسارات عمل مرتبطة بفرع ميزة قديم `feat/deterministic-motion-effects`.
6. **الوزن الثنائي (binary) ثقيل:** 169MB متتبَّعة في Git، منها 81.7MB خطوط و63.9MB صور PNG (الوضعيات + مصادرها)، **بدون Git LFS وبدون `.gitattributes`**.

## 1. المنهجية والبيئة

كل رقم في هذا التقرير مقيس داخل بيئة نظيفة أُنشئت لهذا التحليل:

| البند | القيمة |
|---|---|

**ما شُغِّل فعليًا:**

- `ruff check .` → `All checks passed!`
- `python -m compileall -q tools medo-motion tests` → سليم
- `pytest` كامل **مرتين**: مرة على بيئة Python فقط، ومرة بعد تثبيت أدوات Node
- `npm ci --prefix tools/toolkit` + `node tools/chromium.mjs --check`
- `npm ci --prefix medo-motion/templates/remotion` + `npm run typecheck`
- رندر فعلي لمحرك P: `REEL_MAXFRAMES=3 REEL_CHUNK=3 python medo-motion/templates/procedural-reels/run_all.py`
- `tools/doctor.py` (كامل و`--fast`)، `brand_check.py`، `contrast.py --check`، `techniques.py --validate`، `icons/build.py --check`، `reel_lint.py` على fixture سليم وfixture فاسد
- مسح أسرار/أنماط خطرة، وجرد كامل للأصول والاعتماديات وأحجام Git

**ما لم يُغطَّ (بشفافية):** رندر Remotion فعلي كامل (تحققنا من typecheck فقط)، مسار Whisper/ASR (يحتاج موديل ~250MB)، سكربتات ElevenLabs (تحتاج مفتاحًا مدفوعًا)، وإعدادات GitHub الإدارية (الحماية، القواعد). سجل Git في هذه النسخة **commit واحد مرئي** (نسخة سطحية)، لذلك لا يمكن تقييم تاريخ التطوير.

## 2. هوية المشروع وغرضه

- **المدخلات أربعة فقط:** السكريبت، توجيه المشاهد، تسجيل الصوت (VO)، ومكتبة وضعيات ميدو (موجودة أصلًا: 49 وضعية).
- **VO هو مصدر التوقيت الوحيد:** لا يوجد "طول مستهدف"؛ `tools/vo_length.py` يقيس المدة ويشتق حدود المشاهد من السكتات، والمحركات الثلاثة تمشي على نفس `plan/beats.json`.
- **الهوية مقفولة:** 12 لونًا + مشتق واحد (`ink_shadow`)، و`brand_check.py` يُفشل البناء عند أي لون خارج البالِتة.
- **سياسة "لا لوجو/لا اسم سلسلة":** موثّقة في `brand.json` و`AGENTS.md` ومفروضة في `stage_gate.py` (فحص `G06`). هذا قرار منتج ذكي ومتّسق عبر الطبقات.
- **الاستوديو أداة لا أرشيف:** `projects/*` مستثناة بالكامل، و`*.mp4` و`out/` و`cache/` مستثناة — يمنع تضخّم المستودع بالفيديوهات.

### خريطة التكرار المقصود بين المحركات

| النوع | العدد | الحجم | الملاحظة |
|---|---:|---:|---|

## 5. خط الإنتاج وبوابات الجودة

`tools/pipeline.py` ينفّذ 8 خطوات بترتيب صارم وتوقيت لكل خطوة:

```
vo → lint → brand → mix → render → mux → qa → gate
```

| الطبقة | الأداة | ما تفحصه | العدد |
|---|---|---|---:|
| التوقيت | `vo_length.py --check` | المدة = VO، حدود المشاهد، `frames == round(d×fps)` | عقد واحد |
| الحرفة | `reel_lint.py --scan-code` | كلمات الشاشة، زمن القراءة، شبكة BPM، التباين، منع الأنماط المولّدة | **~45 قاعدة** (`C/S/T/M/U/F/K/O/V/X/W`) |
| الهوية | `brand_check.py` + `contrast.py` | 12 لونًا، تباين WCAG، انحراف المحركات | 3 مراجع توكنز |
| التخطيط | `layout_audit.mjs` (K) · `layout_audit_p.py` (P) | تصادم نصوص/وجوه ومناطق آمنة + replay | L00–L06, F00–F04 |
| الوسائط | `media_qa.py` | H.264/faststart، 1080×1920@30، bitrate، فريم أول، تجمّد، LUFS/TP | **Q00–Q05** |
| المراحل | `stage_gate.py` | intake → plan → render → deliver تراكميًا + checkpoint | **G01–G06** |
| التفسير الهندسي | `machine_explainer.py` | مصادر قابلة للتحقق + احتلال هندسي | X01–X04 |
| الصوت/الكلام | `asr_check.py` | هلوسة Whisper، تكرار، فجوات غير منسوخة | G02 |
| البيئة | `doctor.py` / `selftest.py` | READY / DEGRADED / BLOCKED + رندر دخاني | لكل محرك |

**نتائج التشغيل الفعلي أثناء المراجعة:**

- `doctor.py` الكامل: **DEGRADED** — السبب الوحيد: `drawtext` غير متاح (اختياري، بديل ImageMagick). كل الباقي **OK** بما فيه Chromium وتشكيل العربي.
- `reel_lint` على fixture سليم: `PASS — 0 error, 0 warning · 24s · 100 BPM`.
- `reel_lint` على fixture فاسد: `FAIL — 24 error, 11 warning` (القواعد تشتعل فعلًا، ليست زينة).
- `techniques.py --validate`: `OK 2239 techniques · 48 slots · 44 categories`، والتوثيق المولّد مطابق.
- `icons/build.py --check`: `in sync`. `contrast.py --check`: `PASS`.

**الحكم:** هذه الطبقة هي **أفضل ما في المستودع**. المشروع لا "يدّعي" الجودة؛ يقيسها ويفشل البناء عند فقدانها.

### نقاط القوة

- **أسماء وتوثيق:** كل أداة تبدأ بـdocstring يشرح الاستخدام والحدود والأكواد المرجعية. حتى `conftest.py` يشرح فخًا حقيقيًا في Python 3.10.
- **فصل نقي:** لا `shell=True`، لا `os.system`، لا `eval` لمدخل غير موثوق، وكل `subprocess` بقوائم وسائط.
- **حماية مسارات:** `_safe_paths.checked_path` يرفض symlink والهروب خارج الهدف، ومستخدم في السكافولد و`media_qa` و`render_hybrid`.
- **سلوك "يفشل بصوت عالٍ":** `doctor` لا ينهار عند غياب قدرة، والمحركات ترفض الحالات غير الصالحة بدلًا من إنتاج فيديو ناقص.

### نقاط الضعف البنيوية

1. **تسمية ألوان قديمة مضلّلة:** `EMER=(213,174,166)` (وردي)، `TEAL=(113,113,122)` (رمادي)، `YEL=(217,127,104)` (سالمون)، `GOLD` = وردي. القيم صحيحة لكن الأسماء من بالِتة سابقة، وأي مطوّر جديد سيقرأ "EMER" كأخضر.
