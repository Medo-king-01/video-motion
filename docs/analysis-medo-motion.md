# تحليل حزمة «موشن ميدو» — medo-motion v1.0

> **أرشيف (2026-11):** التحليل ده بيوصف الحزمة الأصلية وألوانها القديمة. البالِت المعتمد دلوقتي `palette v2` (12 لون في `brand/brand.json`)، وأي لون هنا (أحمر `#E5262B`، أصفر، زمردي، تيل) **مش معتمد**.

> الملف اللي وصل: `zip_data.json` (719 KB) = `{"filename":"medo-motion.zip","zip_base64":"..."}`.
> فككته → 87 ملف · ~7,400 سطر كود ونصوص · ~32,800 كلمة إرشادية · صورة واحدة (specimen الخطوط).
> حطيت النسخة المفكوكة في `medo-motion/` جوه الوركسبيس، ومضافة في `.gitignore` (سبب الرخصة تحت في §10).

## 1. الخلاصة في ست سطور

1. ده **مش تطبيق**: ده **مهارة (Skill) لـ Claude Code** — حزمة تعليمات + سكربتات + قوالب، وظيفتها تخلي الموديل يشتغل **مخرج موشن جرافيك** وينتّج MP4 عمودي جاهز للنشر.
2. أصله **«موشن خام» Khaam Motion v1.4.1** لـ خام / راشد الحازمي، وده **نسخة خاصة (fork)** لميدو متضاف عليها 3 حاجات: هويته (`brand/`)، ستايله (`styles/medo-red-circle.md`)، ومحرك ريلز Procedural كامل (`templates/procedural-reels/`).
3. فيه **محركين رندر** مش واحد: **P** = Pillow + OpenCV + FFmpeg (chunks) للريلز اللي فيها شخصية وكروت وأجهزة. **K** = Canvas + Playwright (تايم لاين JS) للتايبوغرافي والقوائم والمشاهد الـ3D.
4. أهم تحويل في النسخة دي: **الهوية مقفولة**. البالِت والخطوط ومناطق الأمان والـ loudness واللهجة ممنوع يسأل عنها أو يغيّرها (`SKILL.md` §Brand lock + `brand/brand.json` كمصدر آلي).
5. طريقة الشغل مش «3 بوابات مراجعة» زي الأصل، لكن **عقد ميدو**: سؤال واحد → يبني → 3 جولات QA بصرية داخلية → **MP4 ماستر** جاهز. البوابات بترجع بس لو ميدو طلب يراجع الخطة.
6. المحتوى عملي جداً ومختبَر جزئياً: `preflight.py` و`brand_check.py` شغالين عندي فعلاً، لكن **FFmpeg وPlaywright وPillow وscipy مش متثبتين هنا**، ولسه فيه تعارضات صغيرة بين ملفات البراند والقوالب (مفصّلة في §9).

## 2. الحزمة بتحل مشكلة إيه بالظبط

المشكلة: كل فيديو موشن عربي بيتكرر فيه نفس الشغل اليدوي — كتابة سكربت، هوك، تصميم، تايبوغرافي عربي سليم (الحروف ما تتكسرش)، مؤثرات، خلط صوت بمستوى معيّن، رندر، تسليم.

الحزمة بتحوّل ده كله لـ **بروتوكول قابل للتنفيذ**:

| الطبقة | بتعمل إيه | الملفات |
|---|---|---|
| بروتوكول | مين يكلّم مين، إمتى يسأل، إمتى يسلّم | `START-HERE.md`, `SKILL.md`, `reference/medo-playbook.md` |
| هوية مقفولة | الألوان، الخطوط، التكوين، الصوت، التصدير | `brand/BRAND.md`, `brand/brand.json`, `styles/medo-red-circle.md` |
| معرفة (تُحمّل عند الحاجة) | تايبوغرافي عربي، هوكات، تصميم، صوت، تسليم | `reference/*.md` (22 ملف) |
| أدوات | فحص البيئة، خطوط، مؤثرات، TTS، تحليل مراجع | `scripts/` (20 سكربت) |
| محركات | رندر فعلي + عناصر جاهزة | `templates/procedural-reels/`, `templates/render/` |

## 4. إزاي بيشتغل من أول مرة لآخر فيديو

**أ. أول تشغيل (بروتوكول `START-HERE.md` — 10 خطوات، خطوة واحدة كل رسالة):**
كشف المضيف (Claude Code ولا شات) → يوصي `/model opus` + `/effort max` → تثبيت المهارة بإذن في `~/.claude/skills/medo-motion/` → `preflight.py` → تثبيت الناقص أداة أداة بإذن → إنشاء أول مشروع (هيكل `plan/`, `assets/`, `out/`, `PROGRESS.md`) → **البراند مقفول فمابيسألش عن ألوان ولا خطوط** → عرض الصوت المعلّق **مرة واحدة بس** وتسجيل الاختيار في `~/.cache/khaam-motion/onboarding.json` → أول فيديو 6–10ث 9:16 → إغلاق التعريف بـ3 نصائح بلغة المستخدم.

**ب. أي فيديو بعد كده (عقد ميدو — المسار الافتراضي):**

```
1) رسالة سؤال واحدة: سكريبت beats مرقمة + ملف الصوت + صور ميدو + اسم السلسلة/اللوجو + أصول زيادة
   (الناقص: قرار مكتوب — chip وصفي، دايرة لوجو فاضية، خط مؤقت، silhouette PLACEHOLDER)
2) اختيار المحرك من جدول playbook §2 (واحد بس للفيديو)
3) Prototype: مشهد واحد → 3 فريمات → contact sheet
4) Validation → Production (chunks) → Polish
5) QA داخلي ≥3 جولات: contact sheet 4–8 فريمات + ffprobe + loudnorm + فحص عربي + brand_check
6) تسليم: MP4 ماستر 1080×1920 CRF13 (المعاينة اختيارية *_preview.mp4) + رسالة 8–10 سطور
```

**ج. الفحص الصوتي/الصوري المفروض قبل أي تسليم** (من `medo-playbook.md` §6):
1080×1920 · 30fps · المدة = مدة الصوت · H.264+AAC+faststart · **−14.5 ±0.3 LUFS** و**≤ −1.5 dBTP** · عربي متصل صحيح في كل مشهد **بالعين** · ضربة واحدة على الأقل في كل مشهد · كابشن مش فوق الرجلين · bitrate **≥ 2.5 Mbps** · placeholders معلنة · `brand_check` نظيف · `CREDITS.md` لكل أصل خارجي.

## 5. قرارات التصميم اللي تستاهل توقف عندها

| القرار | ليه كده | الأثر |
|---|---|---|
| **محركين مش محرك واحد** | P يعطي عمق و«شخصية» أرخص وأسرع على CPU (0.11–0.15 ث/فريم)، K يعطي مرونة تايم لاين وتايبوغرافي | لازم تختار محرك للفيديو الواحد؛ ممنوع الخلط |
| **رندر بالـ chunks (276 فريم)** | الدرس: الرندر الطويل كان بيموت بدون error | استئناف + عملية جديدة لكل chunk + مسح الـ chunks القديمة لو الكود/الأصول اتغيرت (إصلاح خاص بالـfork) |
| **`raqm` إلزامي** | العربي لازم تشكيل صحيح من المحرك نفسه | `raqm=False` → **وقف** وممنوع arabic_reshaper/python-bidi |
| **الكود أولاً، AI تاني، بحث تالت** | يمنع أصول بترخيص مش واضح ويحافظ على اتساق الستايل | برومبت توليد **مقفول** بنفس بالِت البراند + «جلسة واحدة لكل الفيديو» |
| **loudnorm مرحلتين** | الصوت ضعيف (−20) لو مرحلة واحدة | هدف −14.5 ثابت لكل فيديو |
| **الكابشن y≈1455 والرجلين ≤1390** | مشكلة حقيقية حصلت: الكابشن كان يغطي رجل الشخصية | تكوين مقفول في `brand.json` |
| **الذاكرة مقسومة: `TASTE.md` (مشروع) و`user-taste.md` (عبر المشاريع)** | تفضيل عام ≠ إصلاح لمرة واحدة | ما يعيدش السؤال، وما يعمّمش قرار مشروع على الكل |
| **CRF 13 + `tune animation` بدل CRF 17/fast** | «الجودة ضعيفة رغم 1080» كانت مشكلة bitrate | ≥2.5 Mbps شرط قبول، وأقل من 2 مرفوض |

## 6. الهوية المقفولة — الأرقام اللي بتحكم كل حاجة

- **البالِت:** أحمر `#E5262B` · أحمر غامق `#96141A` · أسود `#0A0A0C` · حبر `#18161A`/`#342A2C` · أبيض دافي `#F6F3ED` · أصفر `#F4C430` (غامق فقط) · زمردي `#14B88A` · تيل `#1F8A8A` · دهبي `#CD8C0A` (زينة فقط، تباينه 2.3–2.6:1).
- **الخط:** Cairo ExtraBold/Bold، بديل Tajawal، وDejaVu مؤقت **بشرط الإعلان**. أرقام غربية 0–9.
- **الأمان (9:16):** محتوى مهم y 200–1350 · كابشن 1455 · ممنوع أي حاجة مهمة تحت 1500 · هامش 40px · فراغ رأسي ≤300px · مفيش ساكن >2.5ث.
- **الكابشن:** لوحة `rgba(48,38,40,0.91)` + حد أحمر 3px + 58px + سطرين + عرض ≤970 + كلمة pop + ألوان كلمات مفتاحية (رقم=أصفر، مشكلة=أحمر، إيجابي=زمردي).
- **التوقيع البصري:** دايرة حمرا 80–95% من العرض + بطل 650–1000px ثابت الحجم + HUD (chip y128، progress y64) **بعد** حركة الكاميرا + انتقال مسحة حمرا 0.4ث + زووم 1.00↔1.04.
- **الصوت:** Am–F–C–G · 76 BPM · duck 62% تحت الصوت · مؤثر واحد لكل حركة ≈0.40× ذروة الصوت · TTS بجولتين اختيار (4 بروفايلات) وبعدها صوت واحد بـ atempo 1.15–1.22×.
- **التصدير:** H.264 high/yuv420p · AAC 192–256k · faststart · المدة = الصوت.

## 7. طبقة العربي — أهم جزء تقني في النسخة

`reference/arabic-typography.md` + `templates/render/lib/arabic.js` بيحموا من 3 أخطاء بتضرب أي أداة تايبوغرافي غربية:

1. **ممنوع تفكيك الحروف:** نداء رسم واحد لكل **كلمة**؛ ممنوع per-letter stagger / typewriter حرفي / scramble / letter-spacing.
2. **ممنوع قص النقط:** أي mask أو clip لازم يشيل «صندوق الحبر» كامل + 15% padding، وإلا ب ت ث بتبقى شكل تاني.
3. **الاتجاه:** `ctx.direction='rtl'`, `textAlign='right'`، والحركة والتقدّم بيمشوا يمين→شمال.

الكتالوج البديل اللي بيوفره (كلمة pop، wipe من اليمين، karaoke، weight morph على محور `wght`، outline→fill، slam مع echo، mask للسطر) هو «مفردات حركة آمنة» بديلة للممنوعات — ده أنضج جزء في الحزمة.

## 8. نقاط القوة

1. **مصدر حقيقة مزدوج ومقصود:** `BRAND.md` للبني آدم + `brand.json` للكود، مع `brand_check.py` يقيس فعلاً (WCAG + انحراف بالِت) بدل ما «يفتكر».
2. **كتالوج أخطاء حقيقية** (`medo-playbook.md` §5): chunk بيتعلّق، `TypeError: float` في rounded_rectangle، هالة بيضا حوالين المقدّم، scipy بيرفض wav، HUD بيتقص، bitrate. ده مش كلام نظري — ده سجل أخطاء فعلية.
3. **الأمان المالي والخصوصية:** أي طلب ElevenLabs مدفوع بموافقة + تقدير رصيد؛ المفتاح في متغير بيئة **مش في الشات**؛ preflight بيقول «موجود/مش موجود» بس وما يطبعش القيمة.
4. **الترخيص مسجّل بدقة** لكل أصل: خطوط OFL مع الرخصة، مؤثرات CC0/CC BY مع `CREDITS.md`، و«ترخيص مش واضح = ممنوع».
5. **الصدق في الحدود:** `SKILL.md` بيقول صراحة «متقولش إن الأدوات بتسمع زي البشري»، و**مفيش وعد بتحريك إيد المقدّم**، والـ placeholders لازم تتعلن.
6. **قابلية النقل:** كل السكربتات stdlib في الأساس، إعداد واحد `.khaam/config.json` + متغيرات `KHAAM_*`، سكربتات `.sh` للتوافق.
