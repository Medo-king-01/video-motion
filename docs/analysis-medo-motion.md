# Video Motion — هوية المشروع وبنيته ومصدره

> **تصحيح توثيقي:** حلّ هذا الملف محل تقرير تحليل سابق احتوى على معلومات غير صحيحة عن مصدر المشروع وملكيته، ووصفه باعتباره نسخة من حزمة خارجية. تلك العبارات كانت أخطاء توثيق تولّدت أثناء تعديلات متراكمة بالـVibe Coding، ولا تُعد سجلًا موثوقًا لمصدر الكود أو الحقوق. لا تعتمد على التقرير السابق أو على صياغاته.

## 1. هوية المشروع

**Video Motion** استوديو برمجي لإنشاء فيديوهات وموشن جرافيك محليًا باستخدام أدوات وخطوط عمل قابلة للبرمجة. المشروع يطوره صاحبه، ويضم أدواته وقوالبه وهويته ومكتبة موارده.

المجلد `medo-motion/` هو اسم مسار داخلي لحزمة أدوات المشروع، وليس مشروعًا منفصلًا أو منتجًا خارجيًا.

## 2. البنية الحالية

المستودع مقسّم إلى طبقات واضحة:

| المسار | المسؤولية |
|---|---|
| `tools/` | الإعداد، فحص البيئة، إنشاء المشاريع، الاختبارات، الرندر والتجميع |
| `projects/` | ملفات كل فيديو ومدخلاته وخططه ومخرجاته |
| `medo-motion/brand/` | هوية المشروع وقيم الألوان والخطوط |
| `medo-motion/templates/` | قوالب ومحركات الرندر |
| `medo-motion/motion/` | منحنيات الحركة والتايملاين |
| `medo-motion/icons/` | أيقونات المشروع ومكوّنات الأيقونات الخارجية |
| `assets/` | الخطوط والوضعيات والمؤثرات والاعتمادات |
| `docs/` | الشرح التقني وقرارات التصميم وحدود المحركات |
| `tests/` | اختبارات السلوك والجودة والتوافق |

## 3. محركات الرندر

| المحرك | التقنية | الاستخدام الأساسي |
|---|---|---|
| **P** | Python + Pillow + OpenCV + FFmpeg | المشاهد الإجرائية، الشخصية، الكروت، والنصوص |
| **K** | Canvas + Playwright + Chromium | التايبوغرافي الحركي والواجهات والمشاهد المعتمدة على Canvas |
| **R** | Remotion + React + TypeScript | المشاهد القابلة لإعادة الاستخدام والرسوم المركّبة |
| **Hybrid** | تجميع مقاطع كاملة متتابعة من P/K/R | فيديو يحتاج أكثر من محرك؛ المقاطع متتابعة وليست طبقات متزامنة |

التفاصيل العملية وأوامر التشغيل موجودة في `README.md` و`AGENTS.md`، أما شروط التجميع فتوجد في `docs/hybrid.md`.

## 4. ملكية المشروع وحالة الترخيص

المشروع مستقل، والمواد الأصلية التي أُنشئت له من كود وتوثيق وهوية وقوالب وأدوات هي مواد المشروع ويحتفظ صاحب المشروع بحقوقها.

لا يوجد حاليًا ترخيص Open Source شامل يمنح إذنًا عامًا بإعادة استخدام أو إعادة توزيع المواد الأصلية. ويجب عدم الخلط بين ملكية هذه المواد وبين تراخيص المكتبات أو الأصول الخارجية.

## 5. مكونات الطرف الثالث

وجود مكوّن خارجي لا يجعل المشروع كله تابعًا لمصدر ذلك المكوّن، كما أن ملكية المشروع لا تلغي شروط ترخيص الأجزاء الخارجية. أمثلة موثقة داخل المستودع:

- **itshover icons:** مجموعة الأيقونات المورّدة تحت `medo-motion/icons/itshover/` تحتفظ بترخيص Apache-2.0 وملف الترخيص الأصلي.
- **الخطوط:** عائلات الخطوط المرفقة تحتفظ بتراخيص SIL Open Font License 1.1، مع ملف `OFL.txt` لكل عائلة.
- **منهج الحرفة:** التكييفات المسجلة من دراسة cinetic موضحة في `assets/CREDITS.md`، مع الاحتفاظ بنسبة المصدر وشروط MIT حيث تنطبق.
- **الأدوات والاعتماديات:** FFmpeg وPlaywright وChromium وRemotion وReact وغيرها تخضع لتراخيصها وشروط توزيعها الخاصة.

المرجع المعتمد للتفاصيل هو `assets/CREDITS.md` وملفات الترخيص بجوار كل مكوّن. يجب تحديث سجل الاعتمادات عند إضافة أي أصل خارجي.

- `README.md`: تعريف سريع بالمشروع والإعداد والمحركات.
