# معمارية منصة التحرير — الوثيقة الأولى (المرحلة صفر)

**التاريخ:** 2026-11-12 · **الحالة:** مواصفة معمارية ملزمة للمرحلة صفر · **لا تنفّذ واجهة ولا محركًا.**

هذه الوثيقة هي المرجع الذي تُبنى عليه بقية المراحل. كل بند فيها موسوم بأحد ثلاث حالات:

| الوسم | المعنى |
|---|---|
| **منفّذ** | موجود في الشجرة الآن، ومحروس باختبار أو فاحص، ومذكور اسم الملف |
| **مقترح** | مكتوب هنا كي يُنفَّذ في مرحلة محددة، **ولا يجوز** عرضه في الواجهة قبل ذلك |
| **مرفوض** | قرار صريح بعدم التنفيذ الآن، مع سبب مكتوب |

> الأرقام المولّدة (`AUTO`) لا تُكتب هنا يدويًا؛ تُقرأ من مواضعها. وأي تعارض بين هذه الوثيقة
> و[`unified-project-contract.md`](unified-project-contract.md) في **وصف الموجود** يُحلّ لصالح العقد
> والكود، ثم تُصحَّح هذه الوثيقة.

## 0. القرارات والثوابت

### القرارات المعتمدة (من المالك)

| المحور | القرار | أثره المعماري |
|---|---|---|
| طبيعة المنتج | منصة تحرير فيديو كاملة | المشروع هو الأصل، والفيديو مخرج واحد منه |
| الواجهة | محرر مرئي بجدول زمني | الـTimeline ليس زينة: كل عملية نواة لها تمثيل مرئي |
| الهوية البصرية | هوية واحدة حاليًا | لا طبقة `brand override` ولا multi-tenant قبل الحاجة |
| أساليب الإنتاج | متعددة، غير مقيّدة بقالب | نمط العمل = **مُولِّد مشروع**، لا محرك منفصل |
| المحرك | حتمي، قابل لإعادة الإنتاج، بلا AI | لا قرار تحريري ولا توليد مشهد داخل النواة |

### الثوابت الستة (تُختبَر، لا تُنصح)

1. **لا AI في نواة المحرك:** لا توليد مشاهد ولا اتخاذ قرار قص داخل مسار الرندر. أي أداة مساعدة
   (Whisper/Demucs) تبقى اختيارية وخارج المسار الأساسي، ومخرجاتها بيانات يدخلها المستخدم.
2. **الحتمية:** نفس المشروع + نفس الأصول + نفس إصدار المحرك + نفس `seed` ⇒ نفس الإطارات ونفس
   الصوت. الحتمية تُقاس على مستوى **البكسل والعينة** داخل toolchain مثبَّت؛ تساوي الملف بايتًا ببايت
   يحتاج أيضًا نفس مُرمِّز الفيديو ونسخته، ولا يُدّعى بدونهما.
3. **كل نمط مونتاج ينتج مشروعًا قابلًا للتحرير**، لا فيديو مغلقًا فقط.
4. **P/K/R/Hybrid محركات تنفيذ**، ليست أنظمة مشاريع. لا يملك أي منها تمثيلًا خاصًا داخل المشروع الموحّد.
5. **هوية واحدة**، ولا تعدد هويات قبل حاجة فعلية.
6. **لا ميزة في الواجهة قبل** تحديد: تمثيلها في المشروع، ومعاينتها، ورندرها أو رفضها الصريح.

## 2. نموذج الزمن — الأساس الذي لا يُتفاوض عليه

**منفّذ** في `tools/unified_project_check.py` و`tools/unified_project_time.py`.

| المفهوم | التعريف | القاعدة |
|---|---|---|
| `timebase` | عدد الـticks في الثانية | صحيح موجب؛ كل الأزمنة في المشروع ticks صحيحة |
| `profile.fps` | كسر مختزل `num/den` | `gcd(num, den) = 1` وإلا `U02` |
| `profile.sampleRate` | عينات/ثانية | `timebase % sampleRate == 0` وإلا `U02` |
| حد الإطار | `timebase × den / num` ticks | يجب أن يكون صحيحًا (`U02`) |
| مدى المقطع | `[start, start + duration)` نصف مفتوح | لا تداخل على المسار (`U05`) |
| `duration` المشروع | صريحة، لا تُستنتج | لا يزيد أي مقطع عنها (`U05`) |
| توقيت الـkeyframe | **نسبي لبداية المقطع** | `0 ≤ t ≤ clip.duration` وتزايد صارم (`U06`) |

**ممنوع:** الفاصلة العائمة في أي زمن أو مدة. التحويل إلى إطار/عينة يحدث في المترجم فقط، بالتقريب
المعرَّف (`ceil`) كما في `tools/unified_render_graph.py`.

**مقترح (1.2):** `rate` للمقطع (سرعة) ككسر `{num, den}` مع قاعدة أن `effective source span =
duration × rate`، ورفض أي `rate` لا يحافظ على حدود صحيحة أو يتجاوز مدة الأصل.

## 3. Project Schema

**منفّذ:** `medo-motion/schema/unified-project.schema.json` (إصدارا **1.0** و**1.1**) وفاحص
`tools/unified_project_check.py` (أكواد `U01`–`U06`)، مع `tools/unified_project_author.py`
للإنشاء و`tools/unified_project_store.py` للحفظ الذري.

### 3.1 الموجود الآن، بلا زيادة

| الكيان | الحقول | ملاحظات |
|---|---|---|
| المشروع | `schemaVersion` · `id` · `name` · `profile` · `timebase` · `duration` · `seed` · `assets` · `tracks` | أي حقل مجهول ⇒ رفض |
| الأصل | `id` · `kind` (`video`/`audio`/`image`) · `uri` · `sha256` · `duration` | الصورة بلا `duration`، و`sourceIn` لها صفر |
| المسار | `id` · `kind` (`video`/`audio`/`text`/`graphics`) · `enabled` · `clips` | الأنواع الأربعة **معلنة** لكن مسارات النص/الرسوم تقبل مقاطع فارغة فقط |
| المقطع | `id` · `kind` (`media`) · `assetId` · `start` · `duration` · `sourceIn` · `effects` · `keyframes` | 1.0 يشترط فراغ المؤثرات والمفاتيح |
| المؤثر | `id` · `type` (`opacity`/`gain`) · `version` (1) · `enabled` · `params.value` | وحدات 1/10000، حدود 10000 / 20000 |
| المنحنى | `effectId` · `property` (`value`) · `points[]` | `t` · `value` · `interpolation` (`linear`/`hold`) |

### 3.2 سياسة الإصدارات

- **لا فتح صامت:** إصدار غير معروف ⇒ رفض. لا "أفضل جهد".
- **لا هجرة تلقائية:** المحوّل ينتج **مشروعًا جديدًا + تقريرًا لكل عنصر** (محوّل / مرجعي غير قابل
  للتحرير / غير قابل للتحويل). الأصل يبقى مصدر الحقيقة.
- **إضافة حقل = خمسة أعمال:** schema + قاعدة فاحص + عملية تحرير + قدرة في الـmanifest + اختبار.
  أي حقل بلا الخمسة يبقى **مقترحًا** ولا يدخل schema.

### 3.3 مقترح 1.2 — القائمة المسمّاة (لا أكثر)

| الإضافة | الشكل المقترح | لماذا الآن |
|---|---|---|
| مقطع نصي | `kind: "text"` + `text` · `lang` · `direction` · `fontFamily` · `size` · `colorRole` · `align` · `box` | قلب المنصة العربية؛ بلا نص لا محرر |
| مقطع شكل | `kind: "shape"` + `shape` (rect/ellipse/line) · `box` · `fillRole` · `stroke` | بديل بسيط قبل طبقة الرسوم الكاملة |
| مقطع مُولَّد | `kind: "generator"` + `generator` (اسم من كتالوج) · `params` | Slide Wall / One-Take / Machine Explainer كبيانات لا ككود |
| تحويل المقطع | `transform: {x, y, scale, rotation}` بوحدات صحيحة | أساس Keyframes القادمة |
| سرعة | `rate: {num, den}` | مطلوب للـMontage والتجميع |
| مسار كابشن | `track.kind: "caption"` + مقاطع `cue` | الكابشن ليس نصًا حرًا؛ له توقيت كلمات |
| امتدادات | `extensions: {"x-vendor": {...}}` تُحفظ ولا تُرندَر | يمنع فقد بيانات الغير دون ادّعاء دعم |

**مرفوض في 1.2:** التراكيب المتداخلة (compound/nested timelines)، تعدد الكاميرات في العقد، مسارات
تأثير (adjustment layers)، وأي حقل يعتمد على AI. كلها تعود كإصدار أعلى بعد أن يعمل الأساس.

## 4. Timeline Model

**منفّذ:** `tools/unified_project_edit.py` (عمليات نقية) · `tools/unified_project_history.py` (undo/redo
داخل العملية) · `tools/unified_project_time.py` (snap وحدود وحساب الإطارات/العينات).

### 4.1 قواعد البنية

1. **مسار واحد لكل نوع مقطع:** لا يسمح بخلط `text` و`media` على مسار واحد؛ التحقق من التوافق في
   `U05` بمصفوفة `allowed`. وهذا يمنع "مسار فيديو فيه نص" الذي يكسر كل محرك.
2. **لا تداخل على المسار**؛ الفجوات مسموحة. الترتيب المنطقي = ترتيب `clips` في المصفوفة.
3. **`enabled: false`** يوقف المسار عن الرندر دون حذف بياناته (وعن التصدير الصامت: يُبلَّغ عنه).
4. **الحدود تُقصّ على شبكة الإطارات** في الواجهة؛ النواة تقبل أي tick صحيح وتترك التقريب للمترجم.

### 4.2 العمليات الحالية وحدودها المعلنة

| العملية | تفعل | ترفض صراحةً |
|---|---|---|
| `split_clip` | تقسيم عند tick داخلي، اليسار يحتفظ بالمعرّف | مقطع بمؤثرات أو مفاتيح (حتى يُنفَّذ تحويل المعرّفات والمنحنيات) |
| `trim_clip` | تقصير للداخل فقط | تمديد، أو قص مقطع متحرك |
| `move_clip` | نقل بين المسارات دون تغيير المصدر | تعارض/تداخل، تغيير مدة المشروع |
| `ripple_delete` | حذف مجال وإزاحة اللاحق | مقطع يعبر حد الحذف |
| `History` | undo/redo بذاكرة محدودة | لا يحفظ بين الجلسات |
| `snap` | تقريب حتمي لحدود/شبكة | — |

**مقترح:** `razor` جماعي، `slip`/`slide`، `rate`، `link/unlink` (صوت+فيديو)، و`split` للمقاطع
المتحركة **بعد** تنفيذ `curve.remap` و`effect.clone` كعمليتين خالصتين مختبَرتين.

## 5. Media Asset Model

**منفّذ:** `tools/unified_project_media.py` (فحص/استيراد) · `tools/unified_project_author.py`
(تسجيل/إلغاء تسجيل).

| الحقل/الحالة | القاعدة |
|---|---|
| `uri` | مسار نسبي للمشروع فقط؛ لا `..` ولا `\` ولا `:` ولا محارف تحكم؛ يُرفض symlink عند الفتح (`U04`) |
| `sha256` | 64 hex صغيرة؛ هوية الأصل الحقيقية |
| `duration` | ticks؛ للفيديو/الصوت فقط، والصورة بلا مدة |
| فحص | `ok` · `missing` · `changed` · `error` · `probe_error`؛ `--probe` يطلب ffprobe بعد نجاح البصمة |
| استيراد | نسخ إلى مسار جديد + بصمة + نشر بـhard link؛ لا كتابة فوق موجود |

**مشتقات (مقترح، قابلة لإعادة التوليد دائمًا):** `proxy` (نصف/ربع الدقة)، `thumbnail`،
`waveform` (peaks)، و`probe.json`. مفتاح الكاش = `sha256 + params + generatorVersion`؛ **لا تُحفظ
المشتقات داخل المشروع**، بل في `cache/` خارج Git، وحذفها لا يفقد شيئًا.

**قاعدة الفشل:** أصل `missing` أو `changed` لا يوقف فتح المشروع؛ يوقف **الرندر** ويظهر في الواجهة
كعنصر معطّل مع سبب، ويُسمح بالاستبدال (relink) مع تحديث البصمة صراحةً.

## 6. Effect & Keyframe Model

**منفّذ (1.1 تجريبي):** `opacity` على مسار الفيديو، `gain` على مسار الصوت، قيمة عددية بوحدات
1/10000، ومنحنيات `linear`/`hold` فقط. الاختبارات في `tests/test_unified_project_effects.py`
و`test_unified_project_effect_edit.py`.

### 6.1 هوية المؤثر

`type@version` هي الهوية الدلالية (لا الاسم الحر). كل نسخة جديدة تعني دلالة جديدة؛ لا يُعاد تفسير
`version: 1` أبدًا. المؤثر يحمل `id` فريدًا على مستوى المشروع، و`enabled` مستقل عن وجوده.

### 6.2 القيم والوحدات

| النوع | المدى | الوحدة | ملاحظة |
|---|---|---|---|
| `opacity` | 0 … 10000 | 1/10000 | 10000 = معتم |
| `gain` | 0 … 20000 | 1/10000 | 10000 = بلا تغيير |
| `transform.*` (مقترح) | حسب المحور | ticks للـposition، 1/10000 للـscale | لاحقًا مع المحرك |

**ممنوع:** أي قيمة عشرية داخل المشروع. التحويل يحدث في المحرك.

### 6.3 المنحنيات

- منحنى واحد لكل `effectId` لكل مقطع (`U06` يرفض التكرار).
- `t` نسبي لبداية المقطع، تزايد صارم، أول نقطة قد تبدأ بعد 0 (القيمة قبلها = قيمة المؤثر الساكن).
- `hold` = ثبات حتى النقطة التالية؛ `linear` = استيفاء خطي.
- **مقترح:** `ease` كمعرّف من كتالوج موجود في `shared/js/easing` بدل كتابة منحنيات يدوية، مع نفس
  التنفيذ في P وK (تكافؤ مفروض بـ`cmp`).

**مقترح لاحقًا:** مفاتيح على `transform`, `box`, `volume`, `opacity` للمسار، و`keyframe` بمعرّف
`easing` و`version`. لا تُضاف قبل أن يعمل `curve.remap` على split/trim.

## 7. Render Backend Contract

**منفّذ جزئيًا:** المترجم التجريبي `tools/unified_render_graph.py` (يُنتج graph بـ`executable: false`)،
و`preflight()` يرجع `status: "unsupported"` مع `R01` لكل المحركات. **العقد نفسه مجمَّد في كود**:
`tools/render_backend.py` فيه `RenderBackend` (Protocol) و`conformance_problems()` و`NullAdapter`
لكل محرك، وتوقيعات الدوال محروسة في `tests/test_render_backend_contract.py`. **لا يوجد adapter حقيقي
واحد بعد** — أي باكند لسه بلا adapter بيرجع لـ`NullAdapter` ويعلن `unsupported` صراحةً. الأربعة
(P/K/Hybrid/R) عندهم adapters حقيقيين؛ R بيرفض بـ`R13`/`R14` بالاسم ([`adapter-r.md`](adapter-r.md)).

### 7.1 عقد الـadapter (منفّذ كهيكل — يُنفَّذ محتواه لاحقًا)

كل محرك يقدّم الوحدة التالية، ولا يُقبل محرك بدونها:

```python
capabilities() -> {
  "backend": "P" | "K" | "R" | "Hybrid",
  "backendVersion": "x.y.z",
  "features": {
    "<feature>": {"version": 1, "state": "supported|conditional|unsupported|unknown",
                  "conditions": [...], "evidence": "مسار اختبار أو وثيقة"}
  }
}
compile(project) -> graph          # نفس تحقق النواة أولًا
preflight(graph) -> {"status": ..., "diagnostics": [{"code","path","message"}]}
render(graph, range, out, options) -> {"artifact", "log", "progress"}
cancel() -> None
```

### 7.2 التزامات لا تُتفاوض

1. **لا إسقاط صامت:** ميزة غير مدعومة ⇒ فشل صريح بكود ومسار ورسالة، لا رندر ناقص.
2. **النطاق نصف المفتوح:** `range` بالإطارات/العينات، وعدد الإطارات = `ceil`، والصوت بنفس عدد العينات.
3. **الذرّية:** الكتابة إلى ملف مؤقت ثم نشر؛ لا كتابة فوق ماستر موجود.
4. **بلا شبكة أثناء الرندر.** كل الخطوط والأصول محلية.
5. **نفس الـgraph + نفس الإصدار + نفس `seed` ⇒ نفس الناتج** (بكسل/عينة داخل toolchain مثبَّت).
6. **قدرات مُعلنة:** ما ليس في `features` يُعامل `unknown` ويُرفض، لا يُفترض.
7. **Hybrid:** الطبقة الشفافة تُطلب صراحةً (`alpha`)، والأساس معتم، والحد الأقصى للطبقات كما هو
   منفّذ في v2.2.

### 7.3 حالة المحركات غدًا (لا ادّعاء اليوم)

| المحرك | أول ما يستطيع تنفيذه | ما لا يستطيع |
|---|---|---|
| P | إطارات مُركَّبة بلا متصفح، صوت، نص عربي | شفافية/طبقات Hybrid فوقه كطبقة |
| K | إطارات، alpha، نطاق، كاش مشاهد، نص/أيقونات/انتقالات | عمل بلا Chromium |
| R | مكوّنات React ومدى إطارات | أيقونات/انتقالات P وK، كاش مشاهد |
| Hybrid | تركيب P/R أساس + طبقات K | طبقة K أساس مع طبقة أخرى فوقها |

## 8. Editor Capabilities

**منفّذ:** مبدأ `supported|conditional|unsupported|unknown` في `tools/unified_render_graph.py::preflight`،
وملف القدرات [`backend-capabilities.json`](../medo-motion/schema/backend-capabilities.json) مع فاحصه
`tools/backend_capabilities.py --check` (11 قدرة × 4 محركات) و`tests/test_backend_capabilities.py`.

الفاحص يرفض: محركًا لا يجيب عن قدرة، حالة غير معروفة، `conditional` بلا شرط، `supported`/`conditional`
بلا دليل، دليلًا غير موجود أو خارج المستودع، وحقلًا مجهولًا — ويرفض أيضًا ادّعاء `project.read` أو
`graph.execute` قبل وجود adapter. (هذا الحاجز الأخير يُزال **مع** أول adapter، لا قبله.)

### 8.1 ما تراه الواجهة

لكل ميزة/إصدار: الحالة + شرطها + سبب الرفض + البديل. الواجهة **تحفظ** البيانات غير القابلة للرندر،
وتعطّل التصدير بسببها بدل إنتاج ملف ناقص.

### 8.2 المصفوفة الحالية (من الكود، لا من النوايا)

| القدرة | P | K | R | Hybrid |
|---|---|---|---|---|
| قراءة المشروع الموحّد / تنفيذ graph | غير منفذ | غير منفذ | غير منفذ | غير منفذ |
| Draft نصف المقاس | ✓ | ✓ | ✗ | ✓ (بشروط) |
| كاش على مستوى المشهد | chunks | ✓ | ✗ | حسب المحرك |
| طبقة شفافة في Hybrid | ✗ | ✓ | ✗ | ✓ |
| نص عربي متحرك | ✓ | ✓ | أساسي | حسب الطبقة |
| أيقونات / انتقالات | ✓ | ✓ | ✗ | حسب الطبقة |
| 3D / بيانات | ✗ / ✗ | ✓ / ✓ | ✓ / ✓ | حسب الطبقة |

> المصفوفة تصف **المسارات الحالية**، وليست إقرارًا بأن أي محرك يقرأ العقد الجديد. الصف الأول هو
> السبب الذي من أجله تبدأ المرحلة التالية بـadapter واحد لا بالواجهة.
