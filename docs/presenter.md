# ميدو — مكتبة الوضعيات (Presenter poses)

## اللي عندنا | What ships
**٤٩ وضعية** في **مقاسين (framings)**، كلها PNG شفاف أصلًا (cut-outs جاهزة، مش صور بخلفية):

- **`full`** (٣٠): الجسم كامل، مطبّع على طول ١٢٠٠px، **القدمين على خط الأرض 1390**.
- **`bust`** (١٩): نصف جسم (من الصدر لفوق)، مطبّع على ١١٨٠px، **خط الشعر على الدليل 190**.
  القطع من `full` لـ`bust` بيقرأ كـ**push-in** للكاميرا: نفس الوش في نفس المكان، بس أقرب.

كلها لنفس الشخصية (شعر كيرلي، نضارة، جاكيت أسود فوق تيشيرت أبيض). المصدر: مكتبة ميدو الشخصية
(`Medo-king-01/Medo-s-Personal-Library`)، وكل ملف عنده بصمة في `SOURCE_ID` جوّه الكتالوج.

### الأسماء القديمة | Aliases
`medo_wave` / `medo_think` / `warm` / `puzzled` / `close-neutral` … كلها بتتحوّل تلقائي للوضعية
البديلة القريبة (`ALIASES` في الكتالوج)، فالمشاهد القديمة بتفضل شغالة. لو وضعية قديمة اتحذفت
خالص، احسن حاجة إنك تعدّل المشهد لاسم موجود بدل ما تعتمد على alias.

### إمتى تطلب صورة جديدة | When to ask for a new image
المكتبة هي المدخل الرابع، مش طلب. **اقرأ الكتالوج قبل الـstoryboard** واختار لكل beat وضعية منه —
ده الافتراضي ومحتاجش أي رسالة. اطلب صورة **بس** لما المشهد يحتاج حاجة المكتبة مفيهاش (بروب،
لبس، أو حركة مفيش حد في `poses.json` بيعملها)، وقول في سطر واحد: اسم الوضعية الناقصة والمشهد اللي
محتاجها. إعادة استخدام وضعية «قريبة» أو طلب ٤ صور «للاحتياط» = غلط.

## خط الإنتاج | Production line
```
assets/poses/source/<id>.png     ← القصّة الأصلية زي ما وصلت (شفافة، من غير خلفية)
        │  tools/presenter_build.py   (تقليم + تطبيع الطول + الهوامش)
        ▼
assets/poses/<slug>.png  +  assets/poses/poses.json
```
```bash
python3 tools/presenter_build.py                  # كل الوضعيات + المانيفست
python3 tools/presenter_build.py --only wave,run   # واحدة أو اتنين
make poses                                        # + شيت مراجعة على الخلفية الغامقة (cache/poses-sheet.png)
```
المانيفست فيه لكل وضعية: `ar`, `en`, `tags`, `facing`, `scale`, `framing`, `place`, `w`, `h`,
`feet`, `center`, و`source` (بصمة الملف الأصلي).

**قواعد:**
- الكتالوج (`tools/lib/pose_catalog.py`) هو المصدر: الأسماء، التاجات، الإطار (full/bust)، والـ`SOURCE_ID`.
  ضيف/عدّل هناك وبعدها `make poses` — وبيحدّث كمان النسخ المدمجة في `presenter.py` و`lib/presenter.js`.
- **متعملش تعديل يدوي** على `<slug>.png` ولا على `poses.json` ولا تحط صورة خام في `assets/poses/`.
- خط الإنتاج بيرفض أي مصدر من غير قناة alpha (اختبار بيمسك ده) — يعني الصور لازم تكون مقصوصة.

## الاستخدام | Usage
```js
// engine K
import { loadPoses, PoseTrack } from '../lib/presenter.js';
await loadPoses('/assets/poses/');                  // init()
const act = new PoseTrack([{t: 0, pose: 'neutral'}, {t: 1.5, pose: 'explain'}]);
act.draw(ctx, t, { height: 0.62, x: 0.5 });         // feet land on the ground line (1390)
```
```python
# engine P
from presenter import PoseTrack
act = PoseTrack([{"t": 0, "pose": "neutral"}, {"t": 1.5, "pose": "listen"}])
act.draw(fr, t, height=0.62, x=0.5)
```
```tsx
// engine R — src/lib/Presenter.tsx
import {MedoPresenter} from './lib/Presenter';
<MedoPresenter pose="explain" x={0.72} height={0.55} />
```
- `height` نسبة من 1920 (0.62 = 1190px). المكان بيتحدد من `place` في المانيفست: `feet` → `ground`
  (1390)، و`top` → `top` (190). تقدر تعدّل الاتنين من باراميترات `draw`.
- **خليك جوه نفس الـframing في الجملة الواحدة**؛ القطع بين `full` و`bust` يبقى لحظة قرار (push-in/pull-out).
- الوضعيات اللي فيها قعدة أو جهاز عليها `scale` أقل (`seated-talk` 0.88، `seated-reflect` 0.86،
  `laptop-work` 0.88) عشان ما تبانش أضخم من الواقفين، و`run` 0.94 / `walk` 0.97.
- `PoseTrack` بيعمل cross-fade **مشكّل** (القديم بيخرج في ٦٠٪ والجديد بيبدأ عند ٤٠٪) بمدة 0.12s —
  التغيير بيبان كـbeat cut مش كـdissolve باهت.

## الحياة الخفيفة | Idle life
بدون حركة، الصورة المقطوعة بتبان «ميتة». P/K بيضيفوا الأرقام نفسها (اختبار بيقارنهم)، وR حاليًا بيستخدم subset للتنفس والطلوع/النزول والميل الخفيف عبر `MedoPresenter`:

| الحركة | المعادلة |
|---|---|
| تنفّس | `1 + 0.008·sin(2π·0.28·t)` |
| طلوع/نزول | `2.5·sin(2π·0.22·t)` px |
| ميل جانبي | `2·sin(2π·0.13·t + 0.7)` px |
| ميلان الوضعية | `wave` 1.1° @1.05Hz · `clap` 0.6° @2.2Hz · `run/walk` 1.4° @1.6Hz · `shocked` نبضة سريعة |
| نبض إضافي | `run` 7px @1.6Hz · `walk` 3.5px · `shocked` ضربة واحدة عند كل ثانية |

## المشروع | New projects
`python3 tools/new_project.py <slug>` بينسخ **٤٩ صورة + `poses.json`** جوه المشروع لمحركَي P/K،
وبيضيف نسخة `public/assets/poses/` عشان Remotion (`staticFile()`) يقدر يحمل الصور. المكتبة كاملة
(~٤٤MB) — عشان كده الشغل بيبدأ من الكتالوج مش من طلب صور.

## ملاحظة على المحرك K | Engine-K gotcha
`PoseTrack` بيحلّ الأسماء وقت الرسم (`at()`)، مش وقت الإنشاء — عشان تقدر تعرّف التراك في أول الملف
قبل `await loadPoses()`. لو حلّيتها بدري، أي وضعية مش في القائمة المدمجة هتقع على `neutral` بصمت.

## إضافة وضعية | Adding a pose
1. حطّ القصّة الأصلية في `assets/poses/source/<id>.png` (PNG شفاف، الجسم كامل أو نصف جسم في الفريم).
2. ضيف سطر في `POSES` جوّه `tools/lib/pose_catalog.py` (slug, عربي, إنجليزي, tags, facing, note)،
   وحطّ الـ`<id>` في `SOURCE_ID` — ولو نصف جسم ضيفه في `BUST`.
3. `make poses` → شوف الشيت → لو محتاج مقاس مختلف حط `scale` في `SCALE`.
4. `python3 -m pytest tests/test_presenter.py` — بيتأكد إن الـframing مطابق للمقاس الأصلي، ومفيش
   وضعية بتشاور على نفس الملف، والهوامش والشفافية سليمة.

> **قاعدة الفتحات القديمة:** كانت بتخص مرحلة إزالة الخلفية (أبيض استوديو + ظل رمادي). الحاجتين
> دول مش موجودين في المكتبة الحالية (القصّ جاي جاهز)، فالمعالجة بقت تطبيع + تطبيع مكان فقط.
