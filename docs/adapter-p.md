# محرّك P: أول adapter حقيقي لعقد الـrender

**الحالة:** منفّذ (2026-11-12) · **الكود:** `tools/adapter_p.py` · **الاختبارات:** `tests/test_adapter_p.py` (14) · `tests/test_unified_reference_preview.py` (6)

`docs/editor-architecture.md §7` جمّد العقد قبل وجود أي adapter. المرحلة صفر طلبت **adapter واحد
أولًا** ثم الباقي، وP هو صاحب أعلى تغطية في [`engine-inventory.md`](engine-inventory.md). الملف ده
يسجّل بالضبط إيه اللي P بيرسمه، وإيه اللي بيرفضه، وإزاي القرار محروس باختبار.

## 1. إيه اللي بيشتغل فعلًا

| القدرة | الحالة | الدليل |
|---|---|---|
| `project.read` | supported | `compile()` بيرفض المشروع غير الصالح بـ`InvalidProject` قبل أي إطار |
| `graph.execute` | supported | `compile()` بيرجّع graph بـ`executable: true` وبصمة `graphSha256` |
| `range.render` | supported | `render(graph, (from, to))` نصف مفتوح، ويرفض أي نطاق برّه المشروع بـ`R08` |
| `alpha.layer` | supported | طبقة النص تُركَّب على الصورة بـalpha، ومعاينة = تصدير |
| `text.arabic` | supported | تشكيل عبر `arabic_shape` (HarfBuzz) داخل `unified_reference_preview` |
| `offscreen.render` | supported | مفيش متصفح ولا شبكة في المسار |
| `transitions.catalog` | supported | crossfade + wipe بأربع اتجاهات (حدّ حاد)؛ أي نوع تاني → `R07` |

## 2. إيه اللي بيترفض بالاسم (لا تقريب صامت)

| الكود | الحالة المرفوضة | الرسالة |
|---|---|---|
| `R02` | مسار `graphics` فيه مقاطع | مفيش محرّك بيرسم مسار graphics |
| `R03` | `speed ≠ 1/1` على مسار صوت | مفيش resampler للصوت؛ الفيديو بيدعم السرعة |
| `R05` | أصل مش صورة/فيديو على مسار فيديو | دفاعي: المدقّق بيرفض التوليفة (`U05`) قبل الـadapter |
| `R06` | effect غير `opacity` | شفافية فقط |
| `R07` | transition غير `crossfade`/`wipe`، أو wipe على غير مسار فيديو | الـwipe مالوش هندسة على الصوت |
| `R08` | نطاق إطارات برّه المشروع | النطاق نصف مفتوح ومحدود بـ`frameCount` |
| `R09` | إلغاء مطلوب | إلغاء عند إطار محدد، وبلا أي ملف مؤقت |
| `R10` | مجلد إخراج غير فاضي | لا كتابة فوق عمل موجود |
| `V03` | أصل مش موجود أو بصمته غلط | SHA-256 لازم يطابق |
| `V04` | صورة مش P6 بالمقاس، أو PNG/JPEG مش قابلة للفك | القرار بالبكسل مش بالامتداد |
| `V08` | فيديو مش قابل للفك | فك عبر PyAV، وأول خلل بيوقف النطاق |

`R04` (keyframes) اتشال: الشفافية بالمفاتيح بقت مرسومة. الفيديو والصوت بقوا مقروءين، فـ`R05` بقى
حارسًا دفاعيًا للمخططات اللي تجي من برّه المدقّق، مش قدرة ناقصة. و`R04` كمان غير قابل للوصول لأن
المدقّق بيرفض أي curve بتشاور على effect مش موجود (`U06`) قبل ما الـadapter يشتغل.

الرفض بيحصل في `preflight()` **قبل** أي إطار، والـ`render()` بيعيد نفس الفحص لو حد نادى عليه
مباشرة — مفيش طريق يوصل لملف ناقص.

## 3. الذرّية والقياس

- كل الإطارات تتكتب في مجلد مؤقت جوّه نفس الـparent، وبعد نجاح النطاق كله بيتعمل `move` لاسم
  الإخراج. الإلغاء أو الاستثناء بيمسح المؤقت.
- `render.json` بيسجّل: النطاق، المقاس، صيغة `RGBA8`، بصمة الـgraph، وSHA-256 لكل إطار.
- **المعاينة = التصدير**: الاختبار بيقارن بصمة كل إطار مكتوب ببصمة `render_frame` لنفس الفهرس.
- إطارات الـadapter خام (`frame-00000.rgba`) عن قصد: الضغط للصيغة النهائية شغل `video_export`
  (M01–M07)، والـadapter بيعلن قدرته بدل ما يزوّد مسار ترميز تاني.

## 3ب. النص العربي في الإطار

- النص بيترسم بـ`arabic_shape` (HarfBuzz) فوق صورة الإطار بـalpha، ولون/محاذاة/اتجاه من `texts[]`.
- لو الحجم المطلوب أوسع من الإطار، الـsprite بيتصغّر ليدخل (**مش بيتقص**)؛ والطول كذلك.
- الشفافية على مسار النص بتتطبّق على قناة alpha قبل التركيب.
- **اللفّ والتحريك (1.4):** `text.wrap` بيلفّ على سطور بقياس الشيبـر، و`text.animation` بيرسم
  `fade`/`words-up`/`words-fade` بتعاقب `stagger` و`ease`، بنفس كود المعاينة والتصدير.
- **الحد:** مفيش تحريك حرف‑بحرف ولا تنسيق غني داخل النص، والـwipe بحدّ حاد بلا mask ناعم.

## 4. حدود ما يُدّعى

- **فك الفيديو منفّذ** (PyAV + تصغير bilinear عند المقاس)، وفك الصور PNG/JPEG كذلك. اللي لسه
  مش منفّذ: **فك الصوت جوّه الـadapter** (الصوت بيتجمّع بـ`audio_export` وبيتسجّل كـ`mix.wav` في
  الـmanifest)، و**سرعة الصوت** (`R03`).
- **مفيش** ادّعاء إن P بيساوي K أو R: `backend-capabilities.json` لكل واحد لوحده، والقيد
  `tools/backend_capabilities.py` بيرفض أي `project.read`/`graph.execute` لباكند لسه ماعندوش
  `tools/adapter_<x>.py`.
- **مفيش** byte-reproducibility لـH.264؛ البكسلات هي المثبتة (`decode_fingerprint`).
