# تقرير QA مرئي (HTML)

سجل الطرفية يقول `Q03: Unintended black frame run(s)`. الصفحة دي بتوريك **الإطار** والملاحظات
جنب بعض، مع العتبات اللي اتطبقت — عشان إنسان يحكم على القطع من غير ما يعيد الفيديو كله.
عربي أولًا، RTL، وقابلة للطباعة.

```bash
python3 tools/qa_report.py projects/my-reel --media projects/my-reel/out/master.mp4
# → projects/my-reel/out/qa/report.html  (+ contact-sheet.png بجانبها)
```

## إيه اللي في الصفحة

| القسم | المصدر |
|---|---|
| شريط الحالة (نجح / فشل / ناقص) + بيانات الفيديو | `media_qa.inspect_media` |
| contact sheet | نفس أداة `media_qa` (شيت الإطارات) |
| بنود Final Media QA بالأكواد والمستويات | `media_qa` |
| ملاحظات `reel_lint` | `tools/reel_lint.py --json` |
| العتبات المطبَّقة (LUFS، true peak، bitrate، ثبات) | `media_qa` |
| البيانات الخام | JSON الكامل داخل `<details>` |

## قرارات

- **صفحة واحدة مستقلة**: صورة الشيت مضمّنة `data:image/png;base64`، ومفيش أي `http(s)` —
  تفتح من `file://` أو تتبعت في الشات من غير ما تفقد حاجة.
- **الأداة عرض مش بوابة**: مخرجها `0` لما الصفحة تتكتب، حتى لو الفيديو فاشل — الفشل بيظهر
  في الصفحة نفسها. `2` للحالات اللي الأداة نفسها ما قدرتش تشتغل فيها (ملف ناقص، مكان غير قابل
  للكتابة، رفض الكتابة فوق تقرير قديم من غير `--force`).
- **مفيش كتابة فوق ملف موجود** من غير `--force`، زي بقية أدوات الاستوديو.
- **`--json-out`** بيكتب نفس المحتوى خامًا، للبصمة في CI أو للمقارنة بين نسختين.
- **بدون شبكة**: مالوش داعي يكون عندك إنترنت عشان تراجع فيديو.

## ما هو ليس

- مش بديل عن `stage_gate` — البوابة بتقرر، الصفحة بتشرح.
- مش بيصلح ولا بيعيد رندر؛ الأداة قراءة فقط.
- الألوان والخطوط هنا للعرض فقط (system font) — مش brand lock، لأن الصفحة مش مخرج فيديو.
