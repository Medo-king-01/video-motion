# assets — مدخلاتك المشتركة

| المجلد | إيه اللي تحطه |
|---|---|
| `fonts/Cairo/` | خط Cairo (OFL) — بيجي مع `tools/setup.sh`. لو عندك نسخة أحدث، حطها هنا |
| `poses/` | صور ميدو (بيوّح / بيفكّر / بيشاور) — PNG بخلفية شفافة أو نضيفة. الأنسب ≥1000px عرض |
| `sfx/` | أي مؤثرات صوتية خاصة بيك (اختياري — المحرك عنده مؤثرات procedural) |

الصور بتتنسخ في المشروع عند `tools/new_project.py`، وأي مشروع بياخد
`assets/fonts/Cairo` أوتوماتيك.
