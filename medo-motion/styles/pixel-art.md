# بكسل — Pixel Art (Game Boy)

**الإحساس:** ألعاب، حنين، مرح · **يناسب:** جيمنج، محتوى خفيف، تحدّيات · **المدة:** 8 ث · **المقاس:** 9:16

## البرومبت الجاهز
```
سوّ فيديو موشن ٨ ثواني، عمودي ٩:١٦، بستايل «بكسل» مثل جهاز Game Boy.
كرة بكسل تنط داخل منظر يتحرك جنب (جبال وأشجار بكسل)،
وبعدين تتفكك لمربعات وتتجمع وتكتب الكلمة العربية «حركة» بالبكسل.
أربع درجات أخضر فقط، وتنقيط (dithering)، وحركة متقطعة، وموسيقى 8-bit.
```

## الألوان (لوحة Game Boy)
| الدور | اللون |

| الأغمق | `#0F380F` |
| داكن | `#306230` |
| فاتح | `#8BAC0F` |
| الأفتح | `#9BBC0F` |

## الخطوط
- الكلمة العربية: **Handjet** (بكسل) أو أي خط عريض يُرسم بدقة منخفضة (شوف التقنية)
- إنجليزي: **Press Start 2P**

## الحركة
- كل الحركة على شبكة بكسل (مثلاً 160×288 مكبّرة ×6.75). المواقع تُقرّب لأقرب بكسل.
- إطارات حركة متقطعة: حدّث المشهد على 12 fps حتى لو الرندر 30 fps (`floor(t*12)/12`).
- المنظر: 3 طبقات parallax بسرعات مختلفة.
- التفكك: مربعات تطير بمسارات seeded، ثم ترجع لمواقعها في الكلمة.

## الصوت
- chiptune بسيطة، و«بيب» على كل نطة، وصوت تجمّع في النهاية.
- كلمات بحث Openverse: `8-bit`, `chiptune`, `jump`, `coin`, `retro game`

## التقنية
- ارسم المشهد على canvas صغير (160×288) ثم كبّره بـ `imageSmoothingEnabled = false`.
- **العربي بالبكسل:** ارسم الكلمة **كاملة** بخط عريض على الـ canvas الصغير، ثم كبّرها بدون تنعيم. الكلمة تطلع بكسل وتبقى متصلة. جرّب حجم يخلي النقاط واضحة (2×2 بكسل على الأقل).
- التنقيط: Bayer 4×4 بين درجتين.

## لا تسوي
- ألوان خارج اللوحة الأربع.
- تنعيم أو blur.
- حجم صغير يضيّع نقاط الحروف.
