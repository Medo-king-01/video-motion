# Video Motion — toolkit

هذه الحزمة هي مجموعة الأدوات والموارد الداخلية لمشروع **Video Motion**. اسم المجلد
`medo-motion/` مسار تنظيمي داخل المستودع، وليس اسم منتج أو مشروع خارجي.

## مكونات الحزمة

| المسار | الوظيفة |
|---|---|
| `brand/` | هوية المشروع ومصدر ألوانه وخطوطه ومناطق الأمان |
| `reference/` | أدلة التكوين، والكتابة العربية، والصوت، والتصميم |
| `icons/` | أيقونات المشروع ومكوّنات itshover المنسوبة إلى مصدرها |
| `motion/` | منحنيات الحركة وصيغة الـtimeline المشتركة |
| `styles/` | وصفات بصرية قابلة لإعادة الاستخدام |
| `templates/procedural-reels/` | محرك P: Pillow وOpenCV وFFmpeg |
| `templates/render/` | محرك K: Canvas وPlaywright |
| `templates/remotion/` | محرك R: Remotion وReact وTypeScript |
| `scripts/` | فحوصات الهوية والخطوط والصوت والمعاينة |

## التشغيل

ابدأ من المستودع، وليس من هذا المجلد منفردًا:

1. اقرأ `../AGENTS.md` لفهم عقد التشغيل وقواعد المشروع.
2. اقرأ `../README.md` لنظرة عامة وأوامر الإعداد والفحص.
3. استخدم `../docs/README.md` للوصول إلى توثيق كل محرك ومكوّن.

## الملكية والتراخيص

هذه الحزمة جزء من مشروع Video Motion الذي يطوره صاحبه. أي نصوص قديمة تصفها بأنها
نسخة أو fork من مشروع آخر كانت أخطاء توثيق غير صحيحة، ولا يُعتد بها بوصفها سجلًا
لمصدر الكود أو ملكيته.

تظل تراخيص الأجزاء الخارجية نافذة على الأجزاء التي تغطيها فقط. على سبيل المثال،
مكتبة itshover المضمّنة تحت `icons/itshover/` تحتفظ بترخيص Apache-2.0 وإشعاراتها،
والخطوط تحتفظ بتراخيص SIL OFL 1.1. راجع `../assets/CREDITS.md` وملف الترخيص
الموجود بجوار كل مكوّن خارجي.

لا يوجد حاليًا ترخيص Open Source شامل يمنح حقوقًا عامة لإعادة استخدام أو إعادة
توزيع الكود والمواد الأصلية للمشروع.
