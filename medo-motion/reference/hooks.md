# Hooks: the first 3 seconds

**The hook comes first, the motion serves it.** Beautiful motion that does not stop the scroll is wasted. Every project starts by choosing a hook, then designs the first 3 seconds around it, then the rest.

Why 3 seconds: Instagram's Reels insights report a **skip rate**, the share of viewers who leave within the first three seconds, next to a retention chart for the rest of the video. A high skip rate is a hook problem; a drop later is a content problem. Most feeds start muted, so the hook must work **without sound** and get stronger **with sound**.

## 1. The three-layer hook (all inside 0–3 s)
| Layer | Rule |
|---|---|
| **Visual** | Frame 0 already shows the subject and is already moving. A pattern interrupt: an unexpected object, a big number, something "wrong", a split before/after, a fast push-in, a slam. No fade from black, no logo, no empty build-up. |
| **On-screen text** | ≤ 7 words, big, readable in one second, inside the safe zone, high contrast. It states the curiosity or the benefit. Arabic follows the narration's register (Egyptian dialect (Medo: ar-EG) VO → dialect text). |
| **Audio** | The first spoken line starts within 0.2 s and is ≤ 3 s, or a sound hit lands on frame 0. No music intro before the point. |
The hook opens a loop that the video must close (the payoff). **Claims must be true**: no promise the video does not deliver.

## 2. Hook families (pick by goal; each with an Arabic template and a motion idea)
| Family | Arabic template | First-3-seconds motion |
|---|---|---|
| **Result / number first** | «[رقم] في [مدة]… وهذي الطريقة» | counter rolling to the number + stamp |
| **Warning** | «لا تسوي [X] قبل ما تشوف هذا» | red barrier / ✕ slams over the thing |
| **Curiosity gap** | «السبب الحقيقي ورا [X]… مو اللي تتوقعه» | object half-masked, a reveal starts but stops |
| **Contrarian** | «[شي يسويه الكل]؟ غلط.» | the common belief gets struck through |
| **Pain call-out** | «إذا [مشكلة محددة]… هذا لك» | the pain shown literally (timeline full of clips, clock spinning) |
| **Proof / demo first** | «هذا الفيديو سواه [X]» | the finished result plays first, then «كيف؟» |
| **Before / after** | «قبل… وبعد» | split-screen wipe at 1.0 s |
| **List promise** | «٣ أدوات تختصر عليك [ساعات]» | three slots appear, one by one |
| **Direct question** | «تعرف ليش [X]؟» | the question as giant text, one word at a time |
| **Story mid-action** | «كنت على وشك أحذف الفيديو… لين» | the action is already happening at frame 0 |
| **Identity / POV** | «لو أنت [نوع صانع محتوى]…» | the viewer's situation drawn as UI (their screen, their problem) |
| **Challenge / timer** | «سويت [X] في ١٠ دقايق» | a running timer in the corner from frame 0 |

**Broad beats niche.** For growth, the hook must stop ordinary scrollers, not only experts: lead with a human outcome, a story or humour, and keep jargon and tool names for later in the video.

## 3. Motion rules for 0–3 s
- Frame 0: content + motion + text already on screen. It must also work as a still (it often becomes the cover).
- First visual change by 0.3–0.5 s; two or three changes before 3 s.
- The text hook stays ≥ 1.5 s; captions start immediately.
- One idea only. The visual must **say** the hook literally (see `reference/explainer-reel-system.md` §4), not decorate it.
- Avoid: logo intros, greetings («هلا والله»), slow zooms on nothing, abstract shapes that do not express the hook, a dark empty frame waiting for the voice.
- Optional: make the last frame flow back into the first for rewatches.

## 4. Procedure (every new video)
1. **Research.** If web search is available, run a quick search for current high-performing hooks in the user's niche and language (e.g. «أفضل هوكات ريلز [المجال]», "[niche] reels hooks"), and study any reels the user names. Extract **patterns**, never copy someone's line. Tell the user the sources. Without web access, use the families above.
2. **Write 3 options** from different families. Each = spoken line + on-screen text + the 0–3 s visual/motion idea.
3. **Check each:** readable muted in 1 s? curiosity or benefit clear? true? does the video pay it off? does it speak to the target viewer?
4. **Recommend one inside the plan message (Gate A).** Its frames (frame 0 and ~1.5 s) appear in the storyboard (Gate B). Build the hook first and check it internally with a sheet; no separate 0–3 s review round unless the user asks.
5. **Record** the chosen hook and its family in the project's `TASTE.md` / `PROGRESS.md`. If the user later shares the skip rate or retention chart, log it in `LOG.md` and prefer families that performed.
