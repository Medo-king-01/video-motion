# Medo Playbook — دمج «موشن خام» مع ملف التنفيذ v4
> مصدر الدمج: `reference/source/AGENT_MASTER_BRIEF_v4.md` (النسخة الكاملة الأصلية، ارجعلها للتفاصيل فقط). الكود اتفكّ في `templates/procedural-reels/`.
> **العقد الكامل في `AGENTS.md` بجذر المشروع.** الملف ده بيحل التعارضات ويقول أي محرك.

## 0) لما الاتنين يختلفوا — القرار
| الموضوع | موشن خام | ملف ميدو v4 | **القرار** |
|---|---|---|---|
| لهجة الرد | خليجية بسيطة | عامية مصرية قصيرة | **مصرية** (الكود/التعليقات إنجليزي) |
| مراحل المراجعة | 3 بوابات (خطة/ستوري بورد/معاينة) | اسأل مرة واحدة، سلّم MP4، 3 جولات مراجعة داخلية | **الافتراضي = عقد ميدو** (القسم 1). البوابات التلاتة بترجع لما يقول «عايز أراجع الخطة الأول» أو لو الستايل/الفكرة جديدة |
| الستايل | يبنيه من مراجعك | مقفول (دايرة حمرا، بالِت ثابت) | **مقفول من `brand/`**. تغيير الستايل = موافقة صريحة |
| المحرك | Canvas/Playwright | Pillow+OpenCV+FFmpeg chunks | **اتنين** (القسم 2) |
| الموسيقى | لا موسيقى إلا لو طُلبت | bed بيتخفض تحت الصوت | **bed مفعّل** في نمط A، وفي نمط B خفيف أو من غيره |
| مصدر SFX | مكتبتك ← Openverse ← procedural ← ElevenLabs | procedural (`sfx.py`) | **procedural أولاً** (شغال أوفلاين ومجرّب)، وOpenverse/ElevenLabs ترقية بموافقة وترخيص موثّق |

| المخرج | معاينة بصوت ثم نهائي | ماستر 1080×1920 CRF13 ≥2.5Mbps + معاينة اختيارية | **ماستر دايماً**، والمعاينة `*_preview.mp4` |
| الخطوط | تنزيل OFL بـ get_fonts | Cairo/Tajawal وإلا DejaVu مؤقت | **Cairo** من get_fonts، وبديل مؤقت يتعلن |
| الهوك | بحث + 3 طبقات | السكريبت بييجي من ميدو | **لو السكريبت جاهز: احترمه** وراجع الـ3 ثواني بـ `hooks.md` وقول ملاحظة لو ضعيفة |
| الأصول | `asset-hunting.md` | سلّم: كود ← AI ← بحث | **سلّم القسم 4**، والتوثيق بنظام `CREDITS.md` + manifest الأصلي |

## 1) عقد ميدو (الوضع الافتراضي)
1. الناتج **MP4 جاهز للنشر**، مش خطة ولا ستوري بورد.
2. **المدخلات أربعة بس** (رسالة واحدة لو ناقص حاجة): ① السكريبت beats مرقمة (VO + اللي يظهر) ② **توجيه المشاهد** ③ **ملف صوت التعليق بتاع ميدو** ④ **صور ميدو** (2–4 وضعيات). الباقي كله على الوكيل: الخلفيات والكروت والكابشن والمؤثرات والموسيقى والأصول. اللي ناقص من الأربعة: قرّر واكتب قرارك في سطر (خط مؤقت، silhouette بديل، توقيت مؤقت).
   **ممنوع تسأل عن لوجو أو اسم سلسلة أو رقم حلقة — مفيش حاجة منهم أصلاً.** البطاقات النهائية تايبوغرافي بس.
3. سطر حالة كل ~2 دقيقة في الشغل الطويل.
4. **3 جولات مراجعة بصرية على الأقل** (contact sheet 4–8 فريمات) قبل التسليم، وفحص الـ MP4 نفسه (`ffprobe` + loudnorm + 6 فريمات).
5. اصدق في المش متأكد منه (حدود المشاهد المستنتجة، خط مؤقت، وضعيات بديلة/placeholder).
6. تقدّم على مراحل: **Prototype → Validation → Production → Polish** — مشهد واحد → 3 فريمات → contact sheet → ريندر كامل. متطلعش production من أول محاولة.

## 2) أي محرك؟
| الحالة | المحرك |
|---|---|
| ريل شرح فيه شخصية/مقدّم ميدو + كروت + أجهزة + كابشن (زي ريل اللابتوب) | **P — `templates/procedural-reels`** |
| تايبوغرافي حركي عربي، قوائم/أدوات، 3D، مشاهد ثقيلة، معاينة سريعة بالتايم لاين | **K — `templates/render` (Canvas/Playwright)** |
قاعدة: محرك واحد للفيديو الواحد. نفس البالِت من `brand/brand.json` (K: `lib/brand.js`، P: ثوابت `lib.py`، والتطابق بيتفحص بـ `scripts/brand_check.py --project`).

### تشغيل محرك P (خطوات)
```
mkdir -p <project>/assets <project>/out && cp templates/procedural-reels/* <project>/
python scripts/get_fonts.py "Cairo"            # وحط الخط في <project>/assets/fonts/
python cutout.py white wave.png medo_wave       # أو green لخلفية خضرا (UPLOADS=مجلد الصور)
python -c "from PIL import features; print(features.check('raqm'))"   # لازم True
# عدّل scenes.py: B (حدود المشاهد من silencedetect)، CAPS، THEME/GRID، sceneN، IMPACTS
# CHIP=False افتراضي (مفيش اسم سلسلة). HUD = شريط التقدّم بس.
# عدّل mix.py: جدول E (SFX) + python mix.py out/vo24.wav
python run_all.py                               # chunks قابلة للاستئناف (نفس الأمر لو وقف)
ffmpeg -y -i out/video_only.mp4 -i out/final_audio.wav -c:v copy -c:a aac -b:a 192k -ar 44100 -shortest -movflags +faststart out/<slug>.mp4
```
- ريندر ≈0.11–0.15 ث/فريم على CPU عادي. على Linux: `setsid nohup python3 run_all.py &`. على Windows: `Start-Process python run_all.py -WindowStyle Hidden`.
- **`run_all.py` بيمسح الـ chunks القديمة تلقائياً لو الكود/الأصول/التوقيتات اتغيرت** (إضافة في الدمج ده، الأصل كان بيتخطى أي chunk موجود).
- لو `raqm=False` → وقف وقول لميدو. ممنوع arabic_reshaper/python-bidi.
- حدود المشاهد: `ffmpeg -af silencedetect=noise=-35dB:d=0.35`، ووزّع الجمل عليها، **تحقق بمعدل الكلام 11–16 حرف/ث**، والحد = منتصف السكتة، والمدة النهائية = مدة الصوت.
- نقطة مهمة: `scenes.py` في القالب هو **حلقة اللابتوب** (مثال شغال). خد البنية والعناصر وبدّل المشاهد.

## 3) قواعد التكوين (دي اللي فرّقت بين نسختين لنفس السكريبت)
راجع `brand/BRAND.md` §7. باختصار: بطل واحد كبير · خط أرضي ثابت · مفيش مقطوع من الحافة · مفيش فراغ >300px · عمق (دايرة+ظل) · أحجام نص دنيا · الوش مش صغير · فحص كل مشهد (نص فوق وش؟ حاجة برة [40,1040]×[40,1500]؟ كابشن فوق عنصر مهم؟ نص قريب من لون الخلفية؟).

## 4) سلّم مصادر العناصر
1. **كود** (نص، كابشن، كروت، أشرطة، أسهم، أيقونات، خلفيات، انتقالات).
2. **توليد AI** للبطل اللي الكود بيطلعه باهت (جهاز، منتج، شخصية، سيت أب). برومبت مقفول:
   `Flat vector illustration of <SUBJECT> seen from <ANGLE>, <2–3 details>, clean thick dark outlines, cel-shaded flat colors, no gradients, no text, no logos, no watermark, isolated on a pure white background, centered, product illustration style` + البالِت (جسم #17161b، أحمر #e5262b، شاشة أخضر غامق بأشرطة تيل ونقطة صفرا). **جلسة واحدة لكل الفيديو**، ولو طلع بره الستايل ولّده تاني.
3. **بحث**: CC0/PD/OFL/Unsplash/Pexels/Wikimedia فقط، **نزّله في assets/** (لا hotlink)، وسجّله في `assets/CREDITS.md`: الاسم — الرابط — الترخيص — التاريخ. ترخيص مش واضح = ممنوع.
- بوابات الجودة لأي أصل: يتشاف على أحمر/أسود (مفيش هالة) · بالحجم النهائي · متسق مع الباقي · مراجعة الفريم الكامل. صور ميدو: خد **الهوية** بس، وقوله لو غيّرت الستايل. صورة صغيرة (286×512) → اطلب أصل ≥1000px أو اعرضها ≤1.4× وقول ده.
- مفيش نت؟ اقفل على الكود وقول سطر واحد.

## 5) أخطاء حصلت فعلاً (متكررهاش)
- الريندر الطويل بيقف بدون error → chunks + عملية جديدة لكل chunk + rename ذري.
- `TypeError: float` في `rounded_rectangle` → `int(width*SS)` (متعالج في الـ wrapper).
- نص كارت خارج الكارت → قيس وصغّر تلقائي. · أطراف مقطوعة → هامش 30–40px.
- ظل رمادي/هالة بيضا حوالين المقدّم → قاعدة الظل + erode + اعرض على أحمر.
- scipy يرفض wav → `ffmpeg -i in.wav -ac 1 -ar 24000 -c:a pcm_s16le out/vo24.wav`.
- صوت ضعيف (-20) → loudnorm مرحلتين. · HUD بيتقص → ارسمه بعد الكاميرا.
- «الجودة ضعيفة» رغم 1080 → bitrate: CRF 13 + animation (≥2.5Mbps) وقارن crop خام مقابل نهائي.
- rembg OOM → صغّر لـ h≈1200 بدون alpha_matting. · أصل مبحوث وقّف الريندر → نزّله محلي.
- الكابشن فوق رجلين الشخصية → كابشن y≈1455 والرجلين ≤1390.

## 6) قايمة القبول
1080×1920·30fps·المدة=مدة الصوت·H.264+AAC·faststart · -14.5±0.3 LUFS و ≤-1.5 dBTP · عربي متصل وصحيح في كل مشهد (اتشاف فعلاً) · ثيمات متبدلة وشبكة مختلفة لكل مشهد · حركة+ضربة في كل مشهد، HUD ثابت · كل مشهد اتراجع بصرياً · SFX عند كل حركة والموسيقى بتتخفض · placeholders معلنة · **bitrate ≥2.5Mbps** + مقارنة crop · كل أصل متسق ومفحوص + `CREDITS.md`.
- نتيجة `scripts/brand_check.py` نظيفة (التحذير المعروف عن الدهبي مقبول).

## 7) رسالة التسليم (8–10 أسطر بالمصري)
① اسم الملف + المواصفات (من القياس الفعلي) ② مشهد بمشهد في سطر ③ **اللي مش متأكد منه** (حدود مستنتجة، خط مؤقت، مقدّم placeholder، قيود حركة) ④ الأصول المولّدة/المحمّلة + الترخيص + جملة إن الستايل متسق ⑤ 2–3 تحسينات جاية. **ممنوع تذكر لوجو أو اسم سلسلة — مفيش.**

## 8) قيود معروفة
AI بيطلع صورة واحدة مش سبرايت متحرك (الحركة بالكود) · المقدّم ثابت (bob/tilt) ومفيش تحريك إيد؛ لو عايز أكتر اطلب وضعيات إضافية وبدّل بينها بالزمن · الانتقال رأسي مش قُطري · الموسيقى مصنّعة بسيطة.
