# projects — مساحة عمل مؤقتة، مش أرشيف فيديوهات

**الاستوديو أداة إنتاج، مش ذاكرة فيديوهات.** الفيديوهات اللي خلصت بتتسلّم وتخرج من هنا؛
مفيش مشروع بيفضل في المستودع بعد التسليم، ومفيش مشروع بيترفع على Git.

```bash
python3 tools/new_project.py اسم-المشروع --engine p     # جوه projects/ (متجاهل بالكامل في Git)
python3 tools/new_project.py اسم-المشروع --engine p --out ~/reels/اسم-المشروع
```

`projects/*` مستثنى بالكامل في `.gitignore`، وكل مشروع جديد بياخد ملف `.gitignore` فيه `*`
كحزام تاني. يعني حتى لو حاولت `git add` مشروع، مش هيدخل تاريخ الاستوديو.

بيتعمل:

```
projects/اسم-المشروع/            ← مجلد شغل مؤقت
├── .gitignore      ← `*` — المشروع مش جزء من تاريخ الاستوديو
├── BRIEF.md        ← العناصر الأربعة بس: السكريبت · توجيه المشاهد · الصوت · صور ميدو
├── PROGRESS.md     ← مراحل الشغل (intake → beats → prototype → render → mix → QC → delivered)
├── TASTE.md        ← ذوق المشروع (بيبدأ من قيم البراند المقفولة)
├── plan/
│   ├── script.md   ← السكريبت
│   └── beats.json  ← التوقيتات بعد تحليل الصوت
├── assets/
│   ├── vo/         ← صوت التعليق
│   ├── poses/      ← صور ميدو
│   ├── fonts/Cairo/
│   └── sfx/
├── out/            ← chunks + video_only + المعاينة
└── cache/
```

بعد الملء قول للوكيل: **«اقرأ AGENTS.md وابدأ»**.

ملاحظات:
- `--engine p` بينسخ محرك Pillow/OpenCV في جذر المشروع (زي `medo-playbook.md` §2).
- `--engine k` بينسخ محرك Canvas/Playwright في `src/`.
- `--engine r` بينسخ Remotion، و`--engine hybrid` بينسخ P/K/R لمقاطع متتابعة.
- `--out` بيسمح بمجلد بره المستودع — مفيد لما الفيديو وأصوله تبقى في مكان تاني أصلاً.
- بعد التسليم: امسح مجلد المشروع أو انقله لمكان الفيديوهات بتاعك. المستودع يفضل أداة نضيفة.
